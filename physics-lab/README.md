# PHYSICS LAB 3D

**Физиканы оқыма. Тәжірибе арқылы түсін!** — 7–11 сыныптарға арналған интерактивті 3D виртуалды физика зертханасы.

> Бұл бума репозиторийдегі «Баймұрат батыр» статикалық сайтынан бөлек, дербес қосымша.

## Іске қосу

```bash
cd physics-lab
npm install
npm run dev        # http://localhost:5173
npm test           # физикалық формулалар мен симуляциялардың бірлік сынақтары
npm run build      # typecheck + dist/ өндірістік жинағы
```

**Vercel:** жаңа жоба ашып, *Root Directory* ретінде `physics-lab` көрсетіңіз (Framework: Vite). `vercel.json` SPA бағыттауын қамтиды.

Бір динамометр моделі төрт жұмыста қайта қолданылады. Әр жұмыс 10 қадамнан тұрады: кіріспе → теория → болжам → тәжірибе → өлшеулер → есептеулер → график → қателік → қорытынды → есеп (PDF).

## Архитектура

```
src/
  engines/physics/      формулалар (SI, кіріс тексеруі), қателік, регрессия + сынақтар
  engines/simulation/   нақты уақыттағы модельдер: spring, pull, buoyancy, track (тұрақты қадам 1/600 с)
  data/                 зертханалар, оқу бағдарламасы, тәжірибе конфигурациялары (ExperimentDef)
  three/                LabStage (сахна), parts (динамометр, жүк, серіппе, сызғыш, вектор, drag), scenes/
  features/experiment/  жұмыс барысы, LabView, кесте, график (SVG), талдау, есеп
  pages/                басты бет, каталог, тақырыптар, оқушы/мұғалім кабинеті, нұсқаулық
  lib/                  күй қоймасы (zustand + localStorage), i18n, пішімдеу
```

- **Физика 3D-ден бөлек.** Симуляциялар таза TypeScript класстары; 3D көріністер тек олардың күйін салады, сондықтан 2D балама режимде де сол модель жұмыс істейді.
- **Дайын жауап жоқ.** Көрсетулер модель күйінен құралдың бөлік құнына дейін дөңгелектеліп оқылады; қателік — бөлік құнының жартысы.
- **Жаңа тәжірибе қосу** = `data/experiments.ts` ішіне бір `ExperimentDef` (параметрлер, бағандар, формула, график) + қажет болса жаңа сахна.

## Шектеулер (келесі кезеңдер)

- Қалған зертханалар (жылу, электр, магнит, оптика, толқындар, кванттық) каталогта «Әзірленуде» деп белгіленген.
- Мұғалім кабинеті жергілікті режимде (тапсырма беру, 10–11 сынып бағдарламасын баптау); Supabase синхрондауы, аутентификация әлі жоқ.
- Орыс/ағылшын аудармасы тек навигация мен басты бетте; тәжірибе мазмұны қазақ тілінде.
- 3D модельдер процедуралық (GLB активтерсіз); Rapier қолданылмайды — қозғалыс аналитикалық/сандық теңдеулермен есептеледі.
- AI көмекші қосылмаған.
