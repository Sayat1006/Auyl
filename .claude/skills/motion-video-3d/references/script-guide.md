# Script guide

## Structure (≈45–90 s)
| Part | Time | Purpose | Example |
|---|---|---|---|
| Hook | 0–3 s | Direct question to the viewer, curiosity gap | «Корейлер Қызылордаға қалай жеткенін білесің бе?» |
| Tension / myth-bust | 3–8 s | A common belief → stamp «ҚАТЕЛЕСЕСІҢ» | «Өз еркімен келді деп ойласаң — қателесесің.» |
| Facts | 8–30 s | One fact per scene: date, document, big number, duration | «1937», «170 000+», «БІР АПТА» |
| Turn | 30–40 s | Emotional shift (hardship → humanity / pride) | «Сонда қазақтар оларды құшақ жая қарсы алды.» |
| Result / legacy | 40–50 s | Concrete names, what it changed today | «Ким Ман Сам — Ыбырай Жақаевтың ұстазы» |
| CTA | last 3–5 s | Question or invitation | «Ал сенің ауылыңның атауы қайдан шыққан?» |

Book review variant (worked well): hook → «оқырман ретінде пікірім» → author (born, works, awards) → plot set-up without spoiling the ending → «соңын өздерің оқыңдар» → 2–3 opinion scenes → rating → author quote → next book CTA.

## Writing rules
- Spoken Kazakh, short sentences (≤ 14 words), address the viewer as «сен».
- One idea per scene; each scene gets a 1–3 word UPPERCASE headline that is *not* the subtitle repeated.
- Mark 1–3 keywords per subtitle with `**…**`; negative words get red automatically (жоқ, үрей, суық…), others yellow.
- `say` is what TTS reads: remove «» quotes and parentheses; digits are OK (auto-converted) but read the printed conversion. Spell abbreviations the way they are spoken («МИС» → «Мис»).
- `sub` is what is shown: digits, «», em dashes allowed.
- Don't put opinions in the user's mouth silently: when you write the «менің ойымша» part, tell the user it's your draft and invite edits.
- Don't spoil endings of books/films unless asked.
- Facts: prefer encyclopedias, official/academic pages; when sources disagree, choose the safer wording or omit; list sources at the end. Never invent quotes; quotes the user supplies are fine.
